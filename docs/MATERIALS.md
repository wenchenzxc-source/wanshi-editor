# 油墨堆疊（取代獨立正背面編輯）

目前以一份圖稿搭配 printStack 設定，順序由底材向外：
- cmyk-white：CMYK → 白，從壓克力面觀看。
- white-cmyk：白 → CMYK，從直噴面觀看。
- cmyk-white-cmyk：CMYK → 白 → CMYK，中間白墨、兩側同一份彩色圖稿。只允許透明壓克力或炫彩底材。

UI 不提供獨立正背面切換，duplex 為堆疊設定的衍生欄位，activeFace 固定 front。舊草稿載入時轉換成堆疊模式，舊 face=back 圖層完整保留於 JSON，但不納入目前圖稿的預覽與輸出。舊確認版本及其預先產生的 PNG 不變，舊版雙面 ZIP 仍保留原背面檔案。

新確認版本只產生一份圖稿：final-preview.png、production-with-bleed.png 及可選 uv-mask.png，manufacturing.json 記錄 printStack、底材、觀看面及由底材向外的順序。雙面不輸出第二份獨立排版。

預覽光澤為示意；此編輯器不產生機台白墨分色或自動鏡像。印廠依圖稿與堆疊設定處理分色、白墨覆蓋和鏡像。底材與反光不烘焙進油墨 PNG。

素材庫 DELETE 僅移除庫中顯示，已使用圖層、原檔及已確認製作包保留。圖層面板位於畫布下方，可收合，支援滑鼠與觸控拖曳排序。

印刷順序以選項卡呈現。滑鼠移入／鍵盤聚焦只顯示圖解，不改設定；點選主選項才套用。ⓘ 按鈕提供手機可點閱的說明，圖解含底材側、印刷側與由底材向外的剖面。未選效果明確標註『未套用』，禁用雙面時仍可查看原因與圖解。

## 壓克力磚
新增 acrylic-block-v1，allowedMaterials 僅 clear。尺寸由模板 sizes 定義，設計存 sizeId；初始提供 100×100、100×150、150×200 mm，這是可調整的初始清單，尚未由使用者確認生產規格。厚度未指定，不生成厚度數值；無框磚體預覽邊緣厚度僅示意。
尺寸切換保留圖層 mm 座標與大小，不自動拉伸。前後端共同依尺寸計算畫布、輸出與安全區。確認版本保存當時完整尺寸模板。預設出血 3 mm、安全區 5 mm、300 DPI 亦為初始模板值，可透過 TEMPLATES_FILE 設定。實際製作前需依加工規格調整模板。

## 2026-10-20 規格更新
依使用者提供的長／寬／厚規格表（沿用 mm）：迷你飯友 30×20×5、飯友 50×30×10、小立磚 100×60×20。前述初始 100×100 等尺寸已退役，只在原本使用該規格的舊草稿顯示，不提供給新設計選用。
其他尺寸使用 sizeId=custom、customSize={heightMm:長,widthMm:寬,thicknessMm:厚}，manufacturing.json 的 requiresQuote=true。確認設計不代表報價已確認。自訂長寬工作區限制 11–500 mm、厚 0.1–100 mm，只是系統輸入範圍，不代表工廠承接範圍；仍需另外報價確認。畫布方向只交換視覺長寬，不改實際厚度。出血、安全區與 DPI 仍依模板可設定。
