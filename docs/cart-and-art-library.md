# 原創素材庫與購物車

## 素材授權與來源
素材目錄已更新為自然花材與原創向量。櫻花、玫瑰為內建 image_gen 生成的透明素材，其他向量為此專案繪製。詳見 natural-flowers-and-frames.md 的來源與提示詞。萬事造物及其客戶可將這些素材用於設計、修改及商業商品製作；不宣稱排他著作權或已取得第三方認證。

分類：花瓣、光影星芒、萬聖節、圖框。向量加入設計時產生 1600 × 1600 透明 PNG；AI 花材保留原始 PNG 解析度與透明背景，圖框使用自動貼合的 frame 圖層 並存入該客戶的私有素材空間，使用原有圖層操作、保存及輸出流程。未將素材背景烘焙成格紋。格紋僅為素材庫 UI。加聖誕節等系列時，在 artCategories 及 artCatalog 增加分類／條目即可。

## 購物車
- 確認設計後建立不可變更版本，再以 versionId 加入購物車。
- GET /api/cart：當前私有工作階段的商品、已確認選配、數量。
- POST /api/cart { versionId }：只接受屬於該使用者的已確認版本，同一版本重送不重複增加。
- PATCH /api/cart/:id { quantity }：整數 0–99，0 移除購物車項目（不刪除設計或確認版本）。
- 內容以私有 session owner 儲存在 data/carts，重開頁面仍保留。清除瀏覽器 cookie 會失去此私有工作階段的存取權；尚未整合會員登入。
- 開啟設計編輯，不修改購物車內確認版本；重新確認後可加入新的版本。
- 不估算未提供的價格，不提供假結帳。目前未實作支付與下單。
- WooCommerce 接口預留 designId、versionId、wooCommerceProductId、orderItemId；將 versionId 作為未來 order item metadata，保留數量和選配，不從可變草稿重新生成訂單內容。

## 頁面
精簡頂部品牌與狀態，設計名稱移至「我的設計」。頂部保留商品切換、購物車及主要確認動作。素材分類、工作區、成品預覽與設定分區，手機版商品為兩欄，素材為三欄。
